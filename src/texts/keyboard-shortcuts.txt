Keyboard Shortcuts

FINDER

⌘O — Open
⌃N — New Sprite
⌃W — Close
⌘C — Copy
⌘V — Paste
⌘A — Select All
⌘J — Arrange Windows
Return — Rename
Double-click — Open (double-tap does the same)
Shift-drag — Add or remove icons
Esc — Cancel a drag

EDITOR

⌃N — New…
⌃W — Close
⌘S — Save
⌘D — Duplicate
⇧⌘E — Download
⌃Q — Quit
⌘Z — Undo
⇧⌘Z — Redo
⌘C — Copy
⌘V — Paste
⌘A — Select All
⌘J — Arrange Windows
⌘K — New Layer

S — Selection
B — Pencil
R — Rectangle
G — Fill
E — Eraser
I — Eyedropper
1 to 8 — Layer

Option-click — Pick a color
Right button — Erase
Shift-drag — Square a rectangle, move in a line
Esc — Cancel a drag, drop the selection
Delete — Clear the selection (Edit → Clear)

READER

⌃W — Close
⌃Q — Quit
⌘C — Copy
⌘A — Select All
