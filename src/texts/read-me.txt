SPRITE MACHINE lets you create a 3D model by drawing the 2D faces of the object with simple pixel-art tools.  

The 3D model can exported as a .glb model file or as a sprite atlas of orthographic rotated views for use in a game engine.

We also have a published Sprite Machine npm package that can be used to headlessly create 3D models or Sprite Atlases from the raw PNG Sprite Machine format. This means your game can store its 3D assets as tiny pngs and lazily inflate them into the runtime assets your program needs.


 - - - - NAVIGATING THE APP - - - -

You'll have noticed by now that this app is presented within a classic Macintosh system UI.  This means your files appear as icons on the desktop and you can move them around, rename them, and organize them into folders however you like. 

 - - - - FILE STORAGE - - - -

Your desktop state is preserved via localstorage and the browsers local IndexedDB so your files are all privately saved within your browser and nothing is ever sent to the cloud.

You can use the File > Download menu action to download your file to the desktop as a .png image that can be dragged back into Sprite Machine at any time.

You can also use Special → Back Up All Files… menu action to download a .zip of all of your files. The backup can be dropped into Sprite Machine to restore them.


 - - - - EDITING A FILE - - - -

Double click one of your files to open it in the editor.

The editor has several windows: 

  DOCUMENT
  The drawing canvas for the 2D pixel art faces.
  
  TOOLS
  Basic pixel art tools.
  
  COLORS
  A palette of the colors used in the document.
  
  FACE PICKER
  for choosing which face of the object to display and edit in the document window.
  
  3D MODEL
  for inspecting the current model.


EXPORTING



BACKING UP YOUR FILESYSTEM

Special → Back Up All Files… saves everything at once - every file, every folder and the Trash - as one zip named for the day. Unzip it and you get your folders as folders, your files as .png images and your read-me files as plain text.

To bring a backup back, drag the zip onto the page or choose Special → Restore from Backup… and pick it. You are then asked what to do with it: Add puts the backup's files on the desktop beside the ones already there, and Replace clears the desktop first and puts the backup in its place. Cancel leaves everything as it is.


DRAWING

Pick a tool in the Tools window or with its key: Selection (S), Pencil (B), Rectangle (R), Fill (G), Eraser (E) and Eyedropper (I). The bar under the menu bar shows the tool's settings, with the current color at its left. Click the color to change it, click a swatch in the Color Palette, or Option-click a pixel. Edit → Tile Size… changes the size of the faces, from 1 to 64 pixels.

LAYERS

A part that would get joined to the rest if drawn with it, such as wheels under a car, goes on its own layer. Layer → New Layer… (⌘K) adds one. Switch layers with the keys 1 to 8, the Layer menu's list, or the popup at the bottom of the document window. Check "single layer" in the 3D View to see only the layer you are editing.

SAVING

Documents are saved in your browser and live as icons on the desktop. File → Save (⌘S) saves; the first save asks you to confirm the name. A document that has never been saved is lost if you reload the page. Everything saved comes back: reload and the same windows are open, in the same places. File → Download saves the document to your disk as a .png that holds everything. Drag it onto the page on any computer to open it again.

Drag icons into folders, rename them with Return, and drag them to the Trash to delete them. Special → Empty Trash… is what removes them for good.

EXPORTING

File → Export 3D Model… saves a .glb file, which Unity, Godot, Unreal, Blender and most 3D tools open. File → Export Sprite Atlas… draws the model from a ring of angles and saves the pictures with a data file for 2D engines. View → 3D Sprite Atlas shows the ring before you export.

The full guide is at https://github.com/aportilla/sprite-machine
