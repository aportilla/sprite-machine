SPRITE MACHINE lets you create a 3D model by drawing the 2D faces of the object with simple pixel-art tools.

The finished model can be exported as a .glb model file, or as a sprite atlas for use in a game engine.

We also publish Sprite Machine as an npm package (npm install sprite-machine) that builds models and atlases headlessly from the raw PNG Sprite Machine format. This means your game can store its 3D assets as tiny pngs and lazily inflate them into the runtime assets your program needs.

Sprite Machine is presented within a classic Macintosh system UI. This means your files appear as icons on the desktop and you can move them around, rename them, and organize them into folders however you like.

––––––––––––––––––––––––––––––––––
EDITING A FILE

Double-click one of your files to open it in the editor.

The editor has several windows: 

  DOCUMENT
  The drawing canvas for the 2D pixel art faces.
  
  TOOLS
  Basic pixel art tools. The selection tool's 'on all faces' option moves, flips and deletes a selection on all six faces at once, each the way it sees what you selected.
  
  COLORS
  A palette of the colors used in the document.
  
  FACE PICKER
  For choosing which face of the object to display and edit in the document window.
  
  3D MODEL
  For inspecting the current model.

LAYERS

For more complex models, Sprite Machine supports layers.  Each layer contains the 6 faces of a 3D shape.  The voxel union of all the layer shapes is what defines the final exported 3D model.

Layers allow you to create shapes that would otherwise be impossible to achieve through simple un-projection of a single set of 6 faces.  See the 'Truck' file for an example of a layered document.

EXPORTING

File → Download
Download your file to the desktop as a Sprite Machine formatted PNG image that can be dragged back into Sprite Machine at any time. It holds every face and every layer.

File → Export 3D Model…
Download a .glb model file, which Unity, Godot, Unreal, Blender, three.js and most other 3D tools open with your colors built in. Scale is in voxels per meter, a voxel being the cube one pixel becomes, so at 10 a car 40 pixels long arrives 4 meters long. The 'Lit' export option lets your game's lights shade the model. 'Unlit' keeps your flat colors exactly as drawn. The model's zero point is the middle of the drawing area's floor and Y points up.

File → Export Sprite Atlas…
Download a .zip containing PNG sprite atlas of orthographic views of your 3D model, as well as a TexturePacker JSON file so your sprite can be used in any number of other tools. View → 3D Sprite Atlas shows the row of views, and its settings, before you export.

BACKING UP YOUR FILESYSTEM

Your desktop state is preserved only in localstorage and the browsers local IndexedDB so your files are all privately saved within your browser and nothing is ever sent to the cloud.

Special → Back Up All Files… saves your entire filesystem as one zip named for the day. Unzip it and you get your folders as folders, your files as .png images and your read-me files as plain text.

To bring a backup back, drag the zip onto the page or choose Special → Restore from Backup… and pick it.
